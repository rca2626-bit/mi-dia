# Mi Día

Asistente diario en español para mamá: medicinas, citas, tareas, fechas importantes, alarmas y botones de WhatsApp a la familia.

- `index.html`, `sw.js`, `manifest.webmanifest`, `icon-*.png`: la app publicada (GitHub Pages desde `main`, carpeta raíz).
- `src/app.html`: código fuente; `node build.js` regenera `dist/`.
